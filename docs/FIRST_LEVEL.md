# First playable level

The current native engine supports Fun 1, **Just dig!** It includes original C64
graphics and SID music, Digger, pause, restart, mouse/touch controls and local
Adaptive Player training. See [NATIVE_ENGINE.md](NATIVE_ENGINE.md) for features,
validation and current limits.

The earlier C64 reference milestone used the original program in an emulator.
That separate reference now includes all 100 original levels and the original
non-level screens; see [CAMPAIGN.md](CAMPAIGN.md).
